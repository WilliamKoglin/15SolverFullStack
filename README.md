# 15 Solver Full Stack
This project is a passion project display of hand-coded A* algorithm to solve a 15-puzzle.
Features:
- A* Algorithm and IDA* Algorithm
- Manhattan Hueristic
- FastAPI Backend
- React (Vite) Frontend
- CORS
- API Calls

The project is currently hosted on Render at https://one5solverfullstack.onrender.com/

The spin up and puzzle solve times may take a while due to the fact that it is hosted on the free tier and memory constraints.

This project is still currently in development, with the following features in queue to be implemented:
- Dockerization of application
- Final unit test implementations
